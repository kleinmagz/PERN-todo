# Simple Full-Stack ToDo App

Tried doing a full-stack app using the technologies stated above.
In addition to those, I used TailwindCSS for styling cuz I'm too lazy actually typing css myself.

### Features

- You know what CRUD is right? Basically that.

### Technologies used:

- **PostgreSQL** for database.
- **React** for the frontend.
- **Node.js** and **Express.js** for the backend.
- **TailwindCSS** for styling.
