## How to use it

- Clone this repo.
- Download postgreSQL and PGadmin if you don't have it.
- Make sure your postgresql credentials matches that in /backend/db.js. Or you can edit it yourself to match yours.
- Have two separate terminals to run the backend and the frontend. Enter `npm run dev` for both terminals to run the app.
- In the frontend terminal, there should be a link to localhost, copy that and paste it to your browser of choice.
- **_Voila!_** It's alive!
